## 练习内容

| 文件 | 题目数 | 主要内容 |
|------|--------|----------|
| practice_01_numpy.py | 30 | 数组创建、索引切片、矩阵运算、形状变换、广播机制 |
| practice_02_pandas.py | 20 | DataFrame操作、数据筛选、统计、CSV/JSON读写 |
| practice_03_opencv.py | 15 | 图像处理概念、几何变换、绘制图形、摄像头采集 |
| practice_04_labelstudio.py | 15 | COCO/VOC/CSV格式互转、IOU计算、数据集划分 |
| practice_05_pytorch.py | 20 | 张量操作、神经网络定义、训练循环、模型保存加载 |

## 学习目标

- [ ] 使用NumPy创建和操作多维数组
- [ ] 使用Pandas读写CSV/JSON文件
- [ ] 理解OpenCV图像处理基本概念
- [ ] 实现COCO/VOC/CSV格式的相互转换
- [ ] 使用PyTorch定义神经网络并完成训练循环

## 注意事项

- OpenCV部分需要安装opencv-python并有GUI环境才能显示图像
- 摄像头采集功能需要实际摄像头设备
- 所有代码均为纯Python代码，可直接运行
