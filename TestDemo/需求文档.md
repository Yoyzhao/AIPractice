# 在线刷题系统需求文档

## 一、项目概述

### 1.1 项目背景

开发一个在线刷题练习系统，支持按题型比例随机选题、智能错题复习、答题反馈等功能。

### 1.2 核心功能需求

| 功能 | 说明 |
|------|------|
| 刷题模式 | 按题型比例随机选题，优先选未做错题 |
| 答题反馈 | 答对跳过，答错显示解析 |
| 错题本 | 记录错题、正确答案、用户答案、解析 |
| 题型比例 | 单选题60%、多选题10%、判断题30% |

### 1.3 无需功能

- ❌ 用户注册/登录
- ❌ 考试时间限制
- ❌ 考试防作弊
- ❌ 多人同时在线

## 三、数据库设计

### 3.1 数据表设计

**表1：题目表 (questions)**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER PRIMARY KEY | 题目ID |
| type | VARCHAR(20) | 题型：single/multi/judge |
| content | TEXT | 题目内容（不含选项） |
| options | TEXT | 选项（JSON格式：{"A":"...","B":"...","C":"...","D":"..."}） |
| answer | VARCHAR(50) | 正确答案（如"B"或"ACD"） |
| explanation | TEXT | 解析 |

**表2：用户答题记录表 (user_records)**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER PRIMARY KEY | 记录ID |
| question_id | INTEGER | 题目ID |
| user_answer | VARCHAR(50) | 用户答案 |
| is_correct | BOOLEAN | 是否正确 |
| answered_at | DATETIME | 答题时间 |

**表3：错题本表 (wrong_questions)**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER PRIMARY KEY | 记录ID |
| question_id | INTEGER | 题目ID |
| user_answer | VARCHAR(50) | 用户错选的答案 |
| correct_answer | VARCHAR(50) | 正确答案 |
| explanation | TEXT | 解析 |
| wrong_count | INTEGER | 错误次数 |
| created_at | DATETIME | 首次错题时间 |
| last_reviewed | DATETIME | 最后复习时间 |

**表4：刷题设置表 (settings)**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER PRIMARY KEY | 设置ID |
| single_count | INTEGER | 单选题数量（默认120） |
| multi_count | INTEGER | 多选题数量（默认10） |
| judge_count | INTEGER | 判断题数量（默认30） |
| total_count | INTEGER | 总题目数（默认160） |

## 四、功能模块详细设计

### 4.1 刷题流程

```
开始刷题
    │
    ▼
┌─────────────────────────────┐
│ 1. 按题型比例确定题目数量      │
│    单选:多选:判断 = 60%:10%:30% │
└─────────────────────────────┘
    │
    ▼
┌─────────────────────────────┐
│ 2. 选题优先级                │
│    ① 错题本中的题目           │
│    ② 从未做过的题目           │
│    ③ 已答对但可重复练习        │
└─────────────────────────────┘
    │
    ▼
┌─────────────────────────────┐
│ 3. 随机抽取一道题目          │
└─────────────────────────────┘
    │
    ▼
┌─────────────────────────────┐
│ 4. 显示题目，等待用户作答      │
└─────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│ 5. 用户选择答案并提交                 │
└─────────────────────────────────────┘
    │
    ├─── 答案正确 ────→ 下一题
    │
    └─── 答案错误 ────→ 显示解析 ────→ 记录错题 ────→ 下一题
```

### 4.2 选题算法

```python
def select_next_question():
    """
    选题优先级：
    1. 错题本中的题目（优先复习）
    2. 从未做过的题目
    3. 已答对的题目（可选，用于巩固）
    """
    # 优先：从错题本中选择
    wrong_questions = get_wrong_questions()
    if wrong_questions:
        return random.choice(wrong_questions)

    # 其次：从未做过的题目中选择
    unanswered = get_unanswered_questions()
    if unanswered:
        return random.choice(unanswered)

    # 默认：所有题目随机
    return random.choice(all_questions)
```

### 4.3 答题反馈

| 答题结果 | 处理方式 |
|----------|----------|
| **答对** | 直接跳到下一题，无提示 |
| **答错** | 弹出解析，显示正确答案，记录到错题本 |

### 4.4 错题本功能

| 功能 | 说明 |
|------|------|
| 查看错题 | 列表展示所有错题 |
| 重新答题 | 可再次作答错题 |
| 移除错题 | 答对后自动从错题本移除 |
| 错题统计 | 显示错题数量、正确率等 |

## 五、MD文件解析

### 5.1 MD文件格式

```markdown
# 单选题

1. 以下关于人工智能的说法正确的是？
A. AI就是机器人
B. AI是指使计算机具有智能的技术
C. AI只能处理数值计算
D. AI不需要数据支持

答案：B

解析：人工智能（Artificial Intelligence）是指使计算机具有人类智能的技术...

---

2. （下一题...）
```

### 5.2 解析规则

| 题型 | 判断方式 | 答案格式 |
|------|----------|----------|
| 单选题 | 四个选项A/B/C/D | 单个字母（如B） |
| 多选题 | 标注"多选" | 多个字母（如ACD） |
| 判断题 | 标注"判断"或"对/错" | 对/错 |

## 六、API接口设计

### 6.1 接口列表

| 接口 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 首页，显示刷题界面 |
| `/api/questions/random` | GET | 获取下一道题目 |
| `/api/questions/<id>` | GET | 获取题目详情 |
| `/api/answer` | POST | 提交答案 |
| `/api/wrongbook` | GET | 获取错题本 |
| `/api/wrongbook/<id>` | DELETE | 移除错题 |
| `/api/stats` | GET | 获取刷题统计 |

### 6.2 接口详情

**POST /api/answer**

请求：
```json
{
    "question_id": 1,
    "user_answer": "B"
}
```

响应：
```json
{
    "is_correct": true,
    "correct_answer": "B",
    "explanation": "人工智能是指..."
}
```
